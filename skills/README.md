# skills/

This is where content skills mount. It's empty on purpose.

A skill is a focused instruction file that does one job well: write a LinkedIn post, build a seven-slide carousel, draft a cold email, pull hooks from a transcript. One skill, one job. That's what keeps the output good, instead of one overloaded prompt trying to do everything at once.

Drop your own skills in here as plain files, and the AI will use them.

If you'd rather not build them from scratch, the tested set is the engine that bolts onto this chassis: per-platform content skills, the one-thought-into-a-week-of-posts multiplier, and a quality-control pass that checks every piece before it ships. That's our Content Agent: [growthmodels.co/social-ai-agent/](https://growthmodels.co/social-ai-agent/).
